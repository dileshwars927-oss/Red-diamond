## 🚀 Quick Start

### Prerequisites
- Android device with Termux installed
- Python 3.8+
- Git
- 100MB free space

### Installation

#### Step 1: Clone/Download the project
```bash
cd ~
git clone https://github.com/dileshwars927-oss/DileshOS-Bharat.git
cd DileshOS_Bharat
```

#### Step 2: Run the installer
```bash
chmod +x installer.sh
./installer.sh
```

#### Step 3: Start DileshOS
```bash
python3 main.py
```

## 📦 Installation Manual

### For Termux Users

1. **Update Termux packages:**
```bash
pkg update && pkg upgrade
```

2. **Install required tools:**
```bash
pkg install python
pkg install git
pkg install wget
pkg install curl
pkg install ffmpeg
```

3. **Clone this repository:**
```bash
git clone https://github.com/dileshwars927-oss/DileshOS-Bharat.git
cd DileshOS_Bharat
```

4. **Install Python dependencies:**
```bash
pip install -r requirements.txt
```

5. **Run the installer:**
```bash
bash installer.sh
```

6. **Start the system:**
```bash
python3 main.py
```

## 🐛 Troubleshooting

### Issue: Application won't start
```bash
# Clear cache
python3 main.py --clear-cache

# Reinstall
./installer.sh --reinstall
```

### Issue: Voice commands not working
```bash
# Install voice libraries
pip install pyttsx3 SpeechRecognition
```

### Issue: Network tools not working
```bash
# Install network tools
pkg install nmap net-tools curl
```
